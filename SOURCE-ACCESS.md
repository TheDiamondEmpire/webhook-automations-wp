# Getting the plugin

This repository is the **public showcase** for **Webhook Automations for WordPress**: documentation, client case study, research report and measured results. The plugin itself is distributed as a licensed download.

## What you can do from here

- Read the [README](README.md) for the architecture, engineering decisions, quality bar and an honest list of what is and is not built.
- Read the [client case study](docs/case-study.md) for the business problem, value levers and engagement model.
- Read the [research report](docs/research-report.md) and inspect the raw data in [`results/`](results/) behind every figure.

## What a license includes

- The installable WordPress plugin, version **0.1.0** (`webhook-automations-wp-0.1.0.zip`): install it from **Plugins, Add New, Upload Plugin**
- A license key for 1 site, 5 sites or unlimited sites, with 12 months of updates and support
- The development source (91 files) with the tests and experiment scripts that regenerate everything in `results/`
